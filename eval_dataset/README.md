# Recall Evaluation Dataset

Тестовый датасет из **65 запросов** на русском языке для оценки качества поиска (Recall@K) по корпусу из 500 фильмов (`src/scraper/data/movies_enriched.jsonl`).

## Структура `recall_dataset.json`

Каждый элемент массива `queries` содержит:
- `id` — идентификатор запроса (`q01`..`q65`)
- `category` — категория запроса:
  - `plot` (15) — поиск по описанию сюжета без прямого названия
  - `entity` (15) — поиск по франшизам, группам, персонам и сериям фильмов
  - `thematic` (15) — тематический / жанровый / страновой поиск
  - `vibe` (10) — поиск по настроению и атмосфере
  - `filter_semantic` (10) — запросы с фильтрами по годам и/или рейтингу + семантика
- `query` — текст запроса пользователя
- `qrels` — словарь `{movie_id: relevance}` (`2` — точное попадание, `1` — смежный/дополнительный релевантный результат; для `recall@k` любая оценка `> 0` считается релевантной)
- `expected_titles` — названия релевантных фильмов из датасета для удобного чтения
- `expected_filters` — (опционально) ожидаемые фильтры `year_gte` / `year_lte` / `rating_gte` для категории `filter_semantic`

## Запуск проверки

```bash
uv run python -m test_recall
```
